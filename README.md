## 4. To-Do List API Router

**Tools:** Node.js, JavaScript, JWT, bcrypt, external database
**Methods:** REST API development, authentication, authorization, CRUD operations, data persistence

This project is a full Node.js-based API router developed to provide the backend functionality for a collaborative to-do list web application. The API manages user accounts, tasks, and groups while providing secure authentication and role-based authorization.

Users can create accounts, authenticate through JWT-based access tokens, and manage their own tasks. The API also supports collaborative groups, where users can create or join groups and work with shared tasks. Group owners are assigned administrator roles, allowing them to manage group membership and permissions.

The API uses dedicated routes and data models to handle CRUD operations, with all application data stored persistently in an external database. Authentication and request validation are performed before database operations are executed, ensuring that users can only access and modify resources they are authorized to use.

**Key competencies demonstrated:**

* Backend API development
* Node.js and JavaScript
* RESTful API design
* Authentication and authorization
* JWT and password hashing with bcrypt
* CRUD operations and database integration
* Role-based access control
* Data validation and error handling
* Persistent data management
